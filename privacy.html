プライバシーポリシー

個人用ツール「Kindle 書籍」（以下「本ツール」）での情報の扱いについて定めます。

1. 取得する情報

  • 本ツールは、Google アカウントで利用者が許可した範囲で、Google ドライブにアクセスします。
  • アクセスするのは、本ツールが作成したファイルとフォルダだけです（権限 https://www.googleapis.com/auth/drive.file）。
  • メールアドレス、連絡先、そのほかの Google のデータは取得しません。

2. 情報の使い方

Google ドライブへのアクセスは、利用者自身のファイル（本の PDF と文字のデータ）を、利用者自身の Google ドライブに保存し、保存したものを照合するためだけに使います。

3. 保存する場所

Google から受け取る許可の情報は、利用者のパソコンのキーチェーンにだけ保存します。本ツールにはサーバーが無く、開発者を含め、ほかの場所には送りません。

4. 第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。広告、アクセス解析、追跡のための仕組みも使いません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使用と、ほかのアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

6. 許可の取り消し

Google アカウントのサードパーティのアクセスから、いつでも本ツールへの許可を取り消せます。

7. 改定

このポリシーを改定するときは、このページでお知らせします。
