# suimaa.github.io

個人用ツール「Kindle 書籍」の説明・プライバシーポリシー・利用規約のページ（GitHub Pages）。

- 紹介: https://suimaa.github.io/
- プライバシーポリシー: https://suimaa.github.io/privacy.html
- 利用規約: https://suimaa.github.io/terms.html
- Obsidian で開く（中継）: https://suimaa.github.io/obsidian.html — Notion の目録「書籍・PDF」の列 Obsidian から、自分の Obsidian の保管庫のノートを開く。Notion は `obsidian://` のリンクを開かないので、https のこのページから `obsidian://open` へ移る。保管庫とノートの名前は `#` の後ろ（サーバーに送られない）

紹介・プライバシーポリシー・利用規約は、Google Cloud の OAuth 同意画面（ブランディング）に載せるために置いている。本の中身はここに置かない。
